# HealthyFood Companion

Project scaffold for Discovery Gradhack 2026.

## Overview

This repository contains a starter structure for:
- React Native (Expo) frontend (`/app`)
- FastAPI backend (`/backend`)
- SQL/data prep assets (`/data`)
- Deployment config placeholders (`/infra`)
- Project docs (`/docs`)

## Setup (placeholder)

1. Copy `.env.example` to `.env` in relevant environments.
2. Start backend via Docker Compose.
3. Start Expo app from `/app`.
